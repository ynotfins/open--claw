## Execution Turbulence and Resolution

Two guards surfaced useful implementation facts:

1. The first migration pass rejected `dist\index.js` because the script initially expected `openclaw.mjs`. Installed OpenClaw source, generated service status, version identity, and successful health all proved that `dist\index.js` is the canonical service entry for this release. The migration guard was corrected to distinguish CLI and service entrypoints.
2. `Get-NetTCPConnection` returned false negatives on this host. `netstat.exe -ano -p tcp` consistently exposed the listener and owning PID, so the durable scripts now use `netstat` plus `Win32_Process` validation.

The listener investigation also proved that ClawX had auto-started its embedded gateway on `18789`. The installed ClawX bundle contains an explicit `gatewayAutoStart` contract and executes its gateway start path when that setting is true. The setting was backed up, changed surgically to `false`, and verified after ClawX relaunch.
